# Feature coverage

Features are organized by module and prioritized by dependency order. Each feature is marked with its current status.

This file records broad capability coverage, not actionable task state.

Legend: ✅ implemented at the stated scope | 🚧 active tranche | 🔜 accepted but
not implemented | 💡 possible future capability | ⚠ legacy or limited (read the note). A check mark is capability
coverage, not a production-maturity score; only the backlog defines selectable
work and only progress evidence records completed tranches.
